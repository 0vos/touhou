# ☯️ Touhou Fan-made Game
STG + Tetris, C++ game project in 2024
## 🌟 QuickStart
- Download VisualStudio2022
- Configure VS
- Open the project and run Game.cpp (generate solution)
- Using arrow keys to move and space bar to shoot
    > you will lose lives when you are smashed by blocks
